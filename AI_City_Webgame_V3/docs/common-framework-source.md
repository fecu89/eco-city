# 원본 공통틀: AI 시티 프로젝트 — 공통 설계 틀

> 출처: `AI시티_공통틀_가이드.pdf` — 티처스랩 5기 교사연구회 SCHOOL-X · 과목별 자유 설계 가이드
> 여러 과목 교사가 함께 쓰는 옴니버스 프레임워크 문서. 이 저장소의 게임은 그중 **통합과학(변석환) 버전**을 구현한다.

## 1. 프로젝트 개요

학생이 가상 도시의 '시장'이 되어 AI의 조언을 받으며 도시를 운영한다. 참여 교사마다 하나의 도시 안에서 서로 다른 구역을 맡아, 여러 과목이 하나의 AI 시티를 함께 완성하는 옴니버스 구조 — **단, 이 저장소의 구현 범위는 통합과학 단일 과목 버전이며 멀티 교사 공유 보드는 범위 밖.**

## 2. 고정 뼈대 (모든 버전 공통)

### 2-1. 4차시 흐름
1. **무지성 실행** — 배경지식 없이 AI에게만 묻고 그대로 실행. 숨은 비용(패널티) 비공개.
2. **결과 직면 + 이론 학습** — 패널티(위기 지표) 공개, 위기 원인이 되는 교과 개념 학습.
3. **지식으로 재설계** — 배운 개념을 검증 도구 삼아 AI와 다시 대화, 도시 재구성 + 변경 사유 근거 기록.
4. **발표 + 동료평가** — 완성한 구역/도시 발표, 학급 투표로 동료평가.

### 2-2. 인과 설계 공식 (반드시 지켜야 하는 핵심 규칙)

```
[1차시 무지성 실행] → [부작용] → [부작용의 원인 = 그 교과가 가르치려는 핵심 개념]
  → [개념을 검증 도구 삼은 3차시 재설계] → [재설계 과정에서 드러나는 휴먼스킬]
  → [4차시 발표로 주체성 확인]
```

**가장 중요한 연결고리는 두 번째 화살표.** "부작용의 원인"이 "그 교과의 핵심 개념"과 정확히 같아야, 학생이 "위기를 해결하려 개념을 배우는" 게 아니라 "위기의 정체를 알고 보니 그게 바로 그 개념이었다"는 발견 구조가 만들어진다.

### 2-3. 휴먼스킬 매핑 (별첨4 공식 체계 기준)

| 차시 | 역량 | 핵심 개념 · 관찰 포인트 |
|---|---|---|
| 1차시 | 호기심 | AI는 탐색의 도구이지 끝이 아니다. 관찰: AI에게 던진 질문의 개수·깊이 |
| 2차시 | 성찰적 사고, 통합적 사고 | 되돌아봐야 앞으로 나아갈 수 있다 / 하나의 문제는 여러 분야의 눈으로 볼 수 있다 |
| 3차시 | 비판적 사고, 문제해결 사고 | AI의 답에는 근거가 필요하다 / 문제에 따라 AI를 어떻게 쓸지가 달라진다 |
| 4차시 | 주체성, 윤리적 사고, 사회·관계적 사고 | AI 활용의 결정권은 나에게 있다 / 편리하다고 다 괜찮은 건 아니다 / AI와 일할 때도 사람과의 협력이 중심 |

> school-X 원안은 문제해결 사고를 2차시, 성찰적 사고를 1차시에 배치했으나, 별첨4 정의(성찰은 되돌아볼 결과가 있어야 발현, 문제해결은 재실행 단계에서 발현)에 맞춰 재배치됨.

## 3. 각 교사가 채우는 다섯 질문 — 통합과학(변석환) 버전 답

| 질문 | 통합과학 버전 |
|---|---|
| ① 무지성 실행 | AI 말대로 발전소·데이터센터·공장·주거지 배치 |
| ② 숨은 부작용 | 전력 수급 불균형, 탄소 배출 폭증, 냉각수(물) 부족 |
| ③ 원인 = 개념 | 발전 원리·에너지 효율·신재생에너지의 지속가능성 (성취기준 10통과2-02-05/06) |
| ④ 재설계 미션 | "전력수지≥0, 탄소·물 감소, 인접 보너스 2개 이상"을 조건으로 AI에게 재설계안을 검증형으로 요청 |
| ⑤ 관찰 가능한 휴먼스킬 | 인접 설계 근거 기록 수, 검증형 질문 개수, 재배치 시설 수 |
