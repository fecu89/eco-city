# AI 시티를 구하라! — 게임 설계 (소스 오브 트루스)

> 원본 지도안: [lesson-plan-source.md](./lesson-plan-source.md) · 공통틀: [common-framework-source.md](./common-framework-source.md)
> 이 문서가 실제 구현의 기준이다. 원본 문서와 충돌하면 여기 기록된 2026-08-29 세션의 결정이 우선한다.

## 범위 (중요)

**이 게임은 "수업 중 온디바이스로 플레이하는 부분"만 구현한다.** 지도안의 4차시(발표+시민투표+헌장 서명)는 교실에서 진행하는 오프라인 활동으로 남기고 게임에 넣지 않는다 — 별도 발표 모드, 실시간 학급 투표, 헌장 서명 UI는 **범위 밖**이다. 이유: (1) 여러 학생 기기를 묶는 실시간 투표는 멀티플레이어 서버가 필요한 별개 규모의 작업, (2) 발표·투표는 원래 사람이 진행하는 사회적 활동이라 디지털로 대체할 이유가 약함.

대신 게임 내 플레이 타임이 짧아지는 것을 보완하기 위해 **6단계를 선택적 "보너스 라운드"**로 채워 게임성을 높인다 (아래 6단계 참고).

AI 어드바이저는 **결정형(규칙 기반) 유지** — 실시간 LLM API 연동 없음. 지도안 예산표의 "게임 제작 API/AI 사용료" 항목은 개발 도구 비용으로 해석한다.

## 핵심 인과 사슬 (공통틀 원칙, 반드시 유지)

```
무지성 실행 → 부작용 → 부작용의 원인(=교과 핵심 개념) → 개념을 검증 도구로 쓴 재설계 → 휴먼스킬 발현
```

## 6단계 설계 (기존 4단계에서 확장)

| # | 단계명 | 대응 차시 | 목적 | 신규/기존 |
|---|---|---|---|---|
| 1 | 무지성 실행 | 1차시(45') | AI 조언을 그대로 따라 배치, 대화 자동 저장 | **신규 메커닉** (AI 말대로 짓기 원클릭) |
| 2 | 위기 직면 | 2차시 도입 | 숨은 비용(전력·탄소·물) 대시보드 공개 | 기존 유지 (`revealCrisis`) |
| 3 | 개념 학습 | 2차시 전개 | 발전소·냉각수 퀴즈 + **뇌-AI 에너지 비교** + 성찰 저널 | **신규 콘텐츠** |
| 4 | 진단 | 3차시 도입 | 1차 도시를 항목별로 스캔해 문제 지점 발견 | **신규 단계** (인터랙티브 스캐너) |
| 5 | 재설계 | 3차시 전개 | 6×6 확장, 근거 기록, 재설계 검증 | 기존 유지 (`validateRedesign`) |
| 6 | 시장 성적표 + 보너스 라운드 | (선택, 시간 여유 시) | 등급 연출 + 선택적 챌린지 재도전 | **신규, 선택적** — 발표 대체 아님 |

4차시(발표+투표+헌장)는 게임 밖 교실 활동. 5단계 완료 시 나오는 성적표 화면을 발표 자료로 참고할 수 있으나 전용 기능은 만들지 않는다.

## 단계별 상세 설계

### 1단계 — 무지성 실행
- 기존: 자유롭게 시설 클릭 배치.
- 추가: "AI 조언" 패널에 **"AI 말대로 짓기"** 버튼 — 클릭 시 어드바이저가 특정 시설+칸을 제안하고 원클릭으로 그대로 배치됨 (수동 배치도 계속 허용, 강제하지 않음 — 자유도와 "블라인드 실행" 프레이밍의 균형).
- 모든 AI 질문/응답을 `GameState.transcripts.stage1`에 타임스탬프와 함께 기록. 몇 번 질문했는지 카운트(호기심 관찰 포인트).
- 완료 시 발전점수만 공개, 전력/탄소/물은 `???`로 잠금 (기존 유지).

### 2단계 — 위기 직면
- 기존 `revealCrisis()` 로직 그대로 이식 (대시보드 공개, 화면 흔들림, ALERT 스탬프).
- 패널티 심각도에 따라 흔들림 강도/사운드 세기를 비례시켜 피드백을 더 게임처럼 만든다.

### 3단계 — 개념 학습
- 퀴즈 문항 풀 확장: 기존 4문항 + 신규 뇌-AI 에너지 비교 문항, 매 플레이 일부 무작위 출제(암기 방지).
- **뇌-AI 에너지 저울**: 드래그/홀드 인터랙션으로 저울이 기울어지는 애니메이션. 수치 출처:
  - 인간 뇌: 약 20W (지도안 원문 수치, 여러 출처 일치 — [Texas A&M](https://stories.tamu.edu/news/2025/03/25/artificial-intelligence-that-uses-less-energy-by-mimicking-the-human-brain/))
  - AI 비교치는 출처마다 10배 가까이 차이남을 **그대로 게임 메시지로 활용** — "출처 확인"이라는 지도안의 핵심 메시지와 완벽히 일치. 저울 화면에 "추정치는 출처마다 다르다" 노출 + 출처 링크 2개 제공 ([Intelligence on Twenty Watts](https://johnmiedema.substack.com/p/intelligence-on-twenty-watts), [Human Brains Beat AI by 225,000 Times](https://medium.com/write-a-catalyst/human-brains-beat-ai-by-225-000-times-in-energy-efficiency-762b9327e8ad)).
  - 대표값(수업용 상대값으로 명시): 뇌 20W(지속) vs ChatGPT 클러스터 1000만~2000만W, GPT-3 학습 약 1,300MWh. "같은 지능적 작업에 필요한 에너지가 자릿수 단위로 다르다"는 정성적 결론에 집중.
- 성찰 저널: 1~2문장 텍스트 입력, `GameState.reflections.stage3`에 저장, 내보내기(JSON)에 포함.

### 4단계 — 진단 (신규)
- 1차 도시 스냅샷(`state.firstCitySnapshot`, 기존 코드에 이미 존재)을 다시 렌더링.
- 클릭하면 문제 타일이 하이라이트+파티클로 드러나는 "스캐너" 인터랙션. 힌트 없이 모두 찾으면 보너스 배지.
- 부드러운 진행형(하드 타이머 없음) — 학급 페이스 차이를 존중.

### 5단계 — 재설계
- 기존 로직 그대로 이식: 그리드 6×6 확장, 3단계 전용 시설(태양광/풍력/배터리/냉각/녹지) 해금, 근거 기록(`saveEvidence`), `validateRedesign` 6개 체크리스트.
- 신규: 인접 시너지 성립 시 체인 리액션 VFX, 배치 전 호버 시 지표 변화 미리보기(고스트 프리뷰).

### 6단계 — 시장 성적표 + 보너스 라운드 (선택)
- 기존 `showFinal()`을 등급(S/A/B/C) 연출 + 컨페티로 강화. **"진짜 시장" 명칭은 사용하지 않음** (교실 실제 투표와 겹치지 않도록 "그린시티 인증 등급" 등으로 표기).
- 1단계 대비 5단계의 **성장폭(델타)**을 별도로 표시 — 절대 점수보다 "얼마나 개선했는가"를 강조.
- 선택적 보너스 챌린지 버튼: 예산 20% 삭감 등 변형 조건으로 5단계를 다시 도전. 빨리 끝낸 학생을 위한 확장 콘텐츠 — 필수 아님.

## 승인된 하드닝/폴리시 항목 (7개, 전체 반영)

1. 재시작을 `GameState.reset()`으로 (풀 리로드 제거)
2. 모바일 터치 타겟 32px→44px
3. localStorage 자동저장/이어하기
4. 오디오 다양화 (SFX 세분화 + 저볼륨 옵션 배경음)
5. 퀴즈 문항 확장 + 무작위 출제 (3단계 설계에 통합됨)
6. 완성도 정리 (죽은 텍스트, 비활성 버튼 툴팁 등)
7. 교사용 결과 리포트 (JSON 내보내기 강화 — stage1/stage3 대화록, 성찰 저널, 근거 기록 모두 포함해 "1·3차시 대화록 비교" 평가 방법을 직접 지원)

## 명시적 비범위 (Non-goals)

- 발표 모드, 실시간 학급 투표, 헌장 서명 UI
- 실시간 LLM API 연동 (결정형 어드바이저 유지)
- 배포 (이번 세션은 로컬 완성까지, 배포는 별도 요청 시)
- 멀티 교사/멀티 과목 공유 보드 (공통틀의 옴니버스 구조는 향후 확장 참고용일 뿐)
