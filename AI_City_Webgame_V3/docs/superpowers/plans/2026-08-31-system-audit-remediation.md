# 게임 시스템 감사 후속 구현 계획

## 1. 단일 운영 모델

1. `tests/e2e/unit/economy.spec.js`에 Lv.1/2/3 수입·탄소·물 성장 테스트를 추가하고 실패를 확인한다.
2. 냉각이 떨어져 있을 때 물을 줄이지 않고 데이터센터·핵발전 인접 시에만 줄이는 테스트를 추가한다.
3. 녹지가 실시간 CO₂를 줄이는 테스트를 추가한다.
4. `FacilityOperationSystem.js`를 추가해 레벨별 기본 운영값과 공간 환경 효과를 한 번만 계산한다.
5. `EconomySystem`이 새 운영 모델을 소비하도록 바꾸고 테스트를 통과시킨다.
6. 차트·시설 상세·최종 보고서가 마지막 실시간 운영값을 우선 사용하도록 정리한다.

## 2. 성장 트리 완결

1. `facility-tech.spec.js`에 모든 Lv.3 시설 도달 가능성 테스트를 추가하고 배터리 실패를 확인한다.
2. `renewable3` 결과에 배터리 Lv.3을 추가한다.
3. 관련 연구·업그레이드 테스트를 통과시킨다.

## 3. 원자적 초기화

1. 시뮬레이션 컨트롤러에 재설정 계약 테스트를 추가한다.
2. 0×·1×·4×에서 기본 1×, 진행률 0, 일시정지 사유 없음으로 돌아오는 실패를 확인한다.
3. 컨트롤러 `reset()`과 main의 단일 `resetGame()` 경로를 구현한다.
4. 일반/게임오버 초기화에서 `GAME_RESET`을 발행하고 UI·모달을 동기화한다.
5. 브라우저 초기화 테스트에 실제 컨트롤러 상태 검증을 추가한다.

## 4. 최종 점수 재정의

1. `campaign-report.spec.js`에 오답 퀴즈 무보상, 운영 이력에 따른 점수 차이, 세 영역 합계 테스트를 추가한다.
2. `ReportSystem`에 운영/설계/지식 하위 점수를 구현한다.
3. 성적표 UI와 내보내기에 하위 점수와 정답률을 표시한다.

## 5. 후반 퀘스트 정리

1. 퀘스트 9의 3시간 연속 + 8E 조건과 중단 시 초기화 테스트를 먼저 수정한다.
2. 이름·설명·진행률 표시·판정 로직을 일치시킨다.
3. 퀘스트 14에 Lv.3 시설 또는 통합 연구 조건 테스트를 추가한다.
4. 퀘스트 정의와 판정을 구현한다.

## 6. 연속 캠페인과 회귀 검증

1. 실제 초기 10크레딧, 보상, 정산을 이어가는 결정적 캠페인 테스트를 추가한다.

3. 단위 전체, 핵심 브라우저, 전체 Playwright, 빌드 순으로 검증한다.

5. `progress.md`에 구현 결정, 검증 결과, 잔여 위험을 기록한다.
