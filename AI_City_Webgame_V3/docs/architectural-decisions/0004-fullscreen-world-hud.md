# ADR-0004: 전체 화면 도시 월드와 상호 배타적 HUD

- 상태: 확정 (2026-08-29)
- 관련 결정: [ADR-0003](./0003-city-kit-instanced-renderer.md)

## 결정

- Three.js 도시 캔버스는 뷰포트 전체를 차지하는 고정 월드 레이어로 둔다. 미션, 자원, 건설, AI, 상태, 성취, 설정은 보드 크기를 줄이는 문서 흐름에 참여하지 않는다.
- `WorldHud.js`가 HUD 표시 상태만 관리한다. 활성 패널은 `build`, `advisor`, `status`, `achievements`, `menu` 중 하나이거나 `null`이며, 게임 규칙과 콘텐츠 렌더링은 기존 모듈이 계속 담당한다.
- 데스크톱은 우측 `CITY CONTROL` 레일을 사용한다. 건설은 반복 배치에 유리한 하단 플로팅 팔레트, 상태는 작은 반투명 계기판, AI·성취·메뉴는 우측 drawer다.
- 기존 `top-actions`와 `main-buttons`는 `menuPanel` 안으로 물리적으로 이동한다. 기존 요소 id와 `main.js` 이벤트 연결은 유지해 게임 동작을 바꾸지 않는다.
- 시장 보좌관은 `advisorPanel`, 배지와 근거는 탭을 가진 `achievementsPanel`에 둔다. 근거가 잠긴 단계에서도 탭과 잠금 안내는 보이며 5단계 진입 조건을 설명한다.
- 모바일(폭 760px 이하)은 `건설 · AI · 도시 · 성취 · 메뉴` 5개 하단바와 최대 `56dvh`의 하단 시트를 사용한다. 모든 버튼은 최소 44px 터치 영역을 가진다.
- 단계/도움말/검사 모달은 HUD보다 우선한다. `MODAL_OPEN`에서 열린 HUD를 닫고 제어를 비활성화하며, `MODAL_CLOSE` 뒤 다시 사용할 수 있게 한다.
- 같은 버튼 재클릭, 닫기 버튼, 바깥 클릭, Escape로 패널을 닫고 원래 실행 버튼에 포커스를 돌려준다. `aria-expanded`, `aria-controls`, `aria-hidden`을 동기화하고 `prefers-reduced-motion`을 존중한다.

## 근거

- 도시 건설 게임의 주 화면은 대지와 건축물이며, 기존 2열 대시보드는 3D 도시를 작은 카드 안에 가두고 건설·카메라 조작을 방해했다.
- 모든 도구를 같은 형태의 큰 drawer로 만들면 반복 건설 때 매번 열고 닫아야 한다. 따라서 건설만 하단 팔레트로 유지하고 나머지는 작업 성격에 맞는 drawer/계기판으로 분리했다.
- 상태 패널을 문서 흐름 밖의 고정 계기판으로 두면 열고 닫아도 WebGL 캔버스 크기가 바뀌지 않는다. 실제 측정에서 HUD 30회 전환의 WebGL buffer 생성/삭제는 0/0이다.
- 모바일에서 데스크톱 rail을 축소하면 터치 영역과 텍스트가 지나치게 작아진다. 엄지손가락 영역인 하단바와 제한된 높이의 시트가 게임 화면과 조작성을 함께 보존한다.

## 테스트 영향

- `hud.spec.js`: 단일 활성 패널, Escape/포커스 복귀, 모달 우선순위, 전체 화면 캔버스, 메뉴 소유권, 건설 선택 유지, 상태/성취 패널.
- `mobile.spec.js`: 5개 44px 하단 버튼, 56dvh 시트, 단일 시트, 닫은 뒤 실제 한 손 터치 회전.
- `visual.spec.js`: 데스크톱 기본/건설/상태/메뉴와 모바일 기본/건설 시트 스냅샷.
- `perf.spec.js`: HUD 30회 전환의 WebGL buffer churn 0/0.
- 기존 게임 진행 테스트는 숨겨진 버튼을 강제 클릭하지 않고 실제 HUD를 열어 동작하도록 공용 헬퍼를 사용한다.

## 대안 검토

- **항상 보이는 2열 대시보드 유지**: 구현 변경은 적지만 도시가 화면의 주인공이 되지 못하고 모바일 보드가 더 작아져 기각.
- **모든 기능을 하나의 설정 모달에 통합**: 구조는 단순하지만 건설·AI·상태를 오갈 때 탐색 비용이 커지고 반복 배치가 느려져 기각.
- **건설도 우측 drawer로 통일**: 시각적 일관성은 높지만 여러 시설을 연속 배치할 때 도시를 더 많이 가리고 이동 거리가 길어져 기각.
- **여러 패널 동시 표시**: 비교에는 유리하지만 작은 화면에서 중첩·포커스·입력 충돌이 발생해 단일 활성 패널을 선택했다.
